# NarutoOverlay

Keep an eye on Minecraft performance without covering your screen in debug text. NarutoOverlay brings useful stats into a compact, highly customizable HUD, with each overlay card arranged and tuned to your play style.

## Features

To fit the needs of most players in everyday play, NarutoOverlay defaults to rendering only an **instant FPS** value and the selected theme's backplane. Average FPS, GC and RAM information, text shadows, and other options can be enabled to taste.

- **FPS:** instant, minimum, average, and 1% low readings.
- **Garbage collection:** collector name, pause duration, and time since the last collection.
- **Memory:** used and allocated RAM, usage percentage, and the JVM memory limit.
- **Make it yours:** show only the cards and fields you want, move cards independently, and choose between Naruto-inspired and classic themes. Adjust text shadows, card widths, translucent backplanes, border colors, and update intervals.
- **A little extra polish:** set a custom background image for the configuration screen.
- **Client side only:** No server installation required.

## Controls

Open the chat, then **left-click and drag** a card to move it. **Right-click** any card to open the settings. You can also bind **Reset Text Positions** in the Controls menu.

The immersive in-game configuration screen requires **[ModernUI](https://www.curseforge.com/minecraft/mc-mods/modern-ui)**. It is optional; the cards themselves work without it.
